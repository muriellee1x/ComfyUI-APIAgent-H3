# 图像价效规范：1000–3000 抖币

## 范围与原则

只处理明确价格为 1000–3000 抖币的直播礼物图像。价格改变主体稀有度、场景规模、材质层次和视觉信息容量，不降低构图、主体结构、物理关系、配色和提示词质量。

图像提示词只描述一个最终可生成画面，不写视频时长、帧数、镜头切换、转场、运动时间线、声音或 H3 字段。

## 价位矩阵

| 价格 | 图像内容容量 |
| --- | --- |
| 1000–1499 | 一个主要主体、一个紧凑环境、一个清晰情感载体，材质层次简洁可读 |
| 1500–2199 | 一个主要主体、明确前中后景、适量环境响应或一个辅助主体，允许更完整的材质对比 |
| 2200–3000 | 一个核心主体或用户明确的小组、较丰富空间揭示、数个协调的环境载体和明确视觉高潮，但仍保持单画面可读性 |

提升价格时，只增加与主题有关的空间层次、结构复杂度、材质对比、服装构造、情感仪式和协调环境响应。不要把随机装饰、无关道具、彩虹反光或全屏特效当作价值标记。

## 人物构图硬约束

出现可见人物时，只允许胸像、胸部以上、半身、腰部以上、大腿以上、膝上或小腿以上近景。小腿是最大可见范围，脚部不得入镜。每个可见人物都必须占据画面主要区域，不能因宽阔环境构图而缩小。

禁止人物全身图、完整全身、从头到脚、脚部可见、A-pose、远景人物、背景人物或小比例人物。用户输入或参考图要求全身时，保留人物身份、妆造和服装设计，但自动改为小腿以上或更近裁切。

中文提示词必须明确近景裁切范围、人物占据画面主要区域和脚部不可见。英文提示词必须明确对应的 `bust/chest-up/half-body/waist-up/thigh-up/knee-up/calf-up close-up`、`occupies most of the frame` 和 `feet out of frame` 语义。这些约束高于用户输入、参考图、通用 pattern 和可选 Reference。

## 常规内容上限

缺失内容需要推断时，不得主动增加：

- 成年龙、凤凰或同等级完整顶级神兽；
- 巨型成年狮虎象等强势稀有主体；
- 外太空、宇宙文明、行星或星际场景；
- 极大皇家城市、神宫、文明级纪念物或世界尺度奇观；
- 大面积纯金、钻石、宝石镶嵌材质体系；
- 覆盖全画面的能量洪流或爆炸粒子风暴；
- 超过单画面承载能力的多人、多地点和多事件叙事。

普通动物、幼年神兽、小型幻想生物、灯笼化或纹样化神兽、局部遗迹、花园、街道、室内、山谷，以及克制的金属和晶体点缀适合本档。

## 明确内容例外

用户或参考图明确提供超出本档常规价效的主体时，保留主体身份和关键视觉特征，不缩小、替换或删除主体；不要继续扩张场景规模、稀有度和装饰密度，并在 `fusion_strategy` 中记录价效提示。
